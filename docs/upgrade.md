# 功能选择与旧版升级

本版源码版本为 `1.2.0`。只提供 **基础屏幕版**（大单键、时钟、电量、连接图标、原创机器人），歌词播放器扩展已整体移除。

## 现在只有一种用法

| 需要什么 | 屏幕内容 | 日常依赖 | 入口 |
| --- | --- | --- | --- |
| 基础屏幕版 | 大单键、时钟、电量、连接图标、机器人 | 无电脑后台；原生状态可用于有线 / 2.4G / 蓝牙 | [使用指南](usage.md) |

按键页、时钟、电量与连接图标全部在屏内本地运行，不需要 Node.js、不需要字库、不需要常驻后台。

## 从带歌词的旧版本升级

如果你之前刷过歌词版 IPS（`L6 + LY1`），本版不再提供匹配的固件与后台：

1. **退出并删除旧的歌词后台**（登录自启一并取消），否则它会一直抢占同一个 HID 接口，导致刷机和校时连不上设备。
2. 按 [使用指南](usage.md) 重新烧一次普通主控 + 普通 IPS，然后把同主题 `robot-*.gif` 覆盖 S1。
3. 屏内 `FONT.BIN` 字库不用手工清理：普通 IPS 不读取它，重刷屏幕固件后 `03 / FIRMWARE` 会整片擦除应用区；如果之后想彻底释放空间，用 [vendor/](../vendor/README.md) 里的原厂烧录网页刷回原厂固件即可。
4. 最后连 USB 校一次时，屏幕回到按键页 + 机器人界面。

## 版本、能力与验证

- 原厂主控 `0x3F` 与官方 0.64 `0x40` 使用独立输入 SHA 和地址表，补丁协议均为 `V7.1`。随仓 HTML 仍包含旧 `0x3F`，不能当作 0.64 输入。
- 原厂屏幕 0.02 对应本项目 `L6`（普通 IPS，UI `0.6.3`）。
- 编译、模型、烧录全字节校验、设备应答与用户视觉确认是不同证据，见 [验证说明](validation.md)。不承诺固定帧率、输入延迟或全批次保时。
